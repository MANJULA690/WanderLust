# 🌍 WanderLust

WanderLust is a full-stack web application that allows travel enthusiasts to discover and explore various rental properties around the world.

## 🚀 Tech Stack

- Frontend: HTML, CSS, EJS, Bootstrap

- Backend: Node.js, Express.js

- Database: MongoDB Atlas

## ✨ Features

- User Authentication & Authorization
- Flash Messages for User Feedback
- Image Upload Functionality
- Interactive Map Integration (MapTiler)
- Robust Error Handling
